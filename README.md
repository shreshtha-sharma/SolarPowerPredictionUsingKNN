# ☀️ Solar Power Prediction using Machine Learning

## 🚀 Overview

This project focuses on predicting solar power output using machine learning techniques based on historical weather and generation data.

## 🧩 Problem Statement

Accurate prediction of solar energy output is essential for:

* Efficient energy planning
* Grid stability
* Renewable energy optimization

## 💡 Approach

* Applied **K-Nearest Neighbors (KNN)** algorithm for regression
* Performed data preprocessing and feature selection
* Used historical weather parameters and generation data

## ⚙️ Tech Stack

* Python
* Pandas, NumPy
* scikit-learn
* Jupyter Notebook

## 📊 Results

* Built a working predictive model for solar energy output
* Demonstrated how machine learning can assist in renewable energy forecasting

## 📁 Project Structure

* `Group11_SolarEnergyPrediction.ipynb` → main notebook

## ▶️ How to Run

1. Clone the repository
2. Install dependencies:

   ```
   pip install pandas numpy scikit-learn
   ```
3. Run the Jupyter Notebook

## 📌 Key Learnings

* Applied machine learning to real-world energy data
* Understood model selection and evaluation
* Gained experience in data preprocessing and feature engineering
